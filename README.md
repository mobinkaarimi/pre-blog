# بلاگ دنیارو

طراحی قبلی لغو و پروژه برای پیاده‌سازی یک طرح کاملاً جدید بازنشانی شده است. هنوز پیاده‌سازی طرح جدید آغاز نشده و صفحه فعلی عمداً خالی است.

فونت‌های محلی در `assets/fonts/` و تصاویر نمونه در `assets/images/` بدون تغییر حفظ شده‌اند. این پروژه در ادامه به یک قالب اختصاصی وبلاگ وردپرس تبدیل خواهد شد.
